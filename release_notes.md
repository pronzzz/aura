# Aura Release Notes

## Version 1.0.0 - Initial Release 🎉

Aura is now officially available! This release brings the full power of a Dynamic Island to your Mac.

### key Features
- **Smart Notch**: Uses the actual notch area (or simulates one) for a seamless HUD experience.
- **Universal Player**: Controls native music apps AND web players (YouTube Music/Spotify) automatically.
- **Drop Zone**: Drag & drop files/text to the notch for temporary "shelf" storage.
- **Privacy Core**: 100% offline AI processing, no data tracking, no keystroke logging.

### Improvements
- **Performance**: Optimized resource usage with smart background suspension (App Nap compliant).
- **Stability**: Fixed collection behavior crashes and layout recursion issues.
- **Compatibility**: Works on macOS 14+ with support for all screen types (Notch & Non-Notch).

### Known Issues
- Browser music detection requires the browser window to be visible/active.
- Accessibility permissions are required for window management and browser integration.
